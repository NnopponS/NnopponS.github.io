01 / Engineering case study

WheelSense & EaseAI

From wheelchair motion data to information a care team can use.

WheelSense is a team-built research prototype for assistive care. It connects wheelchair and wearable sensors to mobile and web interfaces for exploring movement, indoor location, and care workflows.

02 / System design

What I helped build

A stream of motion readings is only useful if it reaches the right interface with enough context. My work covered the path from the device to the application.

  1. 01 / Sense

    Embedded firmware

    I contributed to the wheelchair-device firmware. The prototype collects motion data and uses Bluetooth Low Energy (BLE) to connect sensors and support indoor localization.

  2. 02 / Connect

    Telemetry and backend

    I helped connect devices and applications to the backend. MQTT carries telemetry, and the FastAPI service and PostgreSQL database make it available to the application layer.

  3. 03 / Present

    Mobile and web apps

    I contributed to the application workflows. The Flutter gateway pairs with BLE sensors and forwards information to the backend, while the Next.js dashboard presents it to users by role.

03 / Interaction layer

What EaseAI adds

EaseAI is the assistant inside WheelSense. The web interface separates an assistant proposal from execution: a user can review and confirm a proposed action before it runs.

In May 2026, the Thailand Department of Intellectual Property recorded a software copyright registration covering the core EaseAI software architecture. This is a copyright registration, not a patent.

WheelSense is a research prototype, not a clinically validated product.
